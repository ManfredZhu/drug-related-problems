# DRP 验证案例库（20 例）

来源：`《中国药物相关问题分类系统（V1.0）》` 官方案例验证集，20 例均带专家标注的标准编码。

用途：编码前先在本库中找相似案例参照。判定拿不准时，优先套用案例的判定逻辑，而不是自行推断。

---

## 一、药物选择类

### 案例 2 · 重复用药（审方拦截）

男，83 岁，脑梗死。医嘱：舒血宁注射液 20ml+5%GS 250ml 静滴 qd；银杏达莫注射液 25ml+0.9%NS 100ml 静滴 qd。药师审方拦截，因两者均含银杏叶提取物，属重复用药，可致头晕、血压升高或出血风险增大。药师与医生沟通建议选用一种，医生接受并停用银杏达莫。

```
P2.1   E1.1   E2.1   C3.6   I2.3 + I4.2   A1.1   O2.1
```

判定要点：审方拦截、药品未用到患者 → E2.1。重复用药指活性成分或药理作用相同，此处为同一植物提取物。

### 案例 18 · 溶媒选择不当

男，75 岁，急性冠脉综合征。医嘱：多烯磷脂酰胆碱注射液 5ml+0.9%氯化钠 100ml 静滴。该药严禁用电解质溶液稀释，应使用葡萄糖溶液。药师审方拦截并告知医生，医生接受并更改医嘱。

```
P2.1   E1.1   E2.1   C3.1 + C3.5   I2.3   A1.1   O2.1
```

判定要点：溶媒错误同时触犯两个原因——未依据说明书（C3.1）与配伍禁忌（C3.5）。

### 案例 5 · 品种选择不适宜（药物诱发疾病）

男，45 岁，哮喘 20 年，用沙美特罗替卡松吸入剂控制良好。1 月前体检血压 150/110mmHg，服美托洛尔 25mg qd，3 周后哮喘急性发作。医生与药师评估后考虑与美托洛尔相关，建议换用缬沙坦 80mg qd，换药后随访未再发作。

```
P1.1   E1.1   E2.4   C3.1   I2.3 + I4.1   A1.1   O2.1
```

判定要点：β 受体阻滞剂禁用于哮喘 → 未依据禁忌症选药（C3.1）。患者已发生急性发作（实际伤害）→ E2.4。

### 案例 8 · 剂型选择不适宜

女，79 岁，帕金森病，服左旋多巴/苄丝肼胶囊。随访时家属反馈患者逐渐出现吞咽困难，胶囊喂不进去。药师与医生沟通建议改为分散片（可打碎水中分散），医生接受并执行。

```
P1.1   E1.1   E2.4   C3.4   I2.3 + I4.1   A1.1   O2.1
```

判定要点：药物本身选对了，是剂型不适合患者当前生理状态 → C3.4，不是 C3.1。

### 案例 6 · 重复用药 + 药物重整

女，65 岁，5 天前分别就诊心内科与内分泌科，两位医师均因"睡眠障碍"开具镇静安眠药。患者主诉服药后整天昏沉，药师查询发现其同服阿普唑仑 0.4mg qn 与艾司唑仑 1mg qn，联系医生后告知患者停服一种，停艾司唑仑后症状消失。

```
P2.1   E1.1   E2.4   C2.6 + C3.7   I2.3 + I3.1 + I4.2   A1.1   O2.1
```

判定要点：同一患者在不同科室就诊导致用药重复 → 药物重整问题（C2.6）；药理作用不同但治疗目标一致 → C3.7。已发生昏沉（实际伤害）→ E2.4。

### 案例 11 · 无指征用药（医师侧）

女，65 岁，甲减、骨质疏松、糖尿病、高脂血症。处方：艾司唑仑片 7 片 每次 1 片 口服 每晚。前置审方系统提示缺少适应症，药师建议增加"睡眠障碍"诊断，医生接受并执行。

```
P3.2   E1.1   E2.1   C3.9   I2.3   A1.1   O2.1
```

判定要点：无对应诊断即用药 → 不必要的药物治疗（P3.2）+ 无指征用药（C3.9）。责任在医师 → E1.1。

### 案例 20 · 药品无法获得

患者长期服拜新同（硝苯地平控释片），互联网医院续方时提示药物不可选。药师回复：本院无拜新同，但有相同有效成分及剂型的药物。患者表示明白，但仍希望服用拜新同，打算去其他医院看看。

```
P3.3   E1.5   E2.2   C3.10   I4.1   A2.3   O1.1
```

判定要点：问题出在药品供应，责任方既非医师也非患者 → E1.5。患者未接受替代方案（其他原因）→ A2.3。结局不明 → O1.1。
注意：患者未接受但药品尚未更换，故 E2.2（到达患者但无伤害）。

## 二、用法用量与疗程类

### 案例 3 · 药物相互作用（双硫仑样反应）

男，44 岁，肺部感染。处方：头孢地尼分散片 每次 1 片 口服 tid；复方甘草口服溶液 每次 10ml 口服 tid。药师前置审方拦截，因复方甘草口服溶液含酒精，与头孢同服可发生双硫仑样反应，建议更换不含酒精的止咳药水，医生接受并更改。

```
P2.1   E1.1   E2.1   C3.5   I2.3 + I4.1   A1.1   O2.1
```

判定要点：药物与药物联用不适宜（C3.5）。前置审方拦截 → E2.1。

### 案例 9 · 用法不当（不可直接输注）

男，81 岁，脑梗死。医嘱：丙氨酰谷氨酰胺注射液 50ml 静脉滴注 qd。该药为高浓度溶液，输注前须与氨基酸溶液混合后再与载体一起输注。审方药师拦截并电话沟通，医生接受，改为加入三升袋中使用。

```
P2.1   E1.1   E2.1   C4.5   I2.3 + I4.8   A1.1   O2.1
```

判定要点：给药方式错误 → C4.5（用法不当），不是 C3 药物选择问题。

### 案例 4 · 给药途径错误

男，70 岁，COPD 急性加重、社区获得性肺炎。药师审核医嘱时发现艾普拉唑肠溶片用法用量为 5mg iv qd，说明书给药途径为口服。药师建议改为 5mg 口服 qd，医生接受并更改。

```
P3.3   E1.1   E2.1   C4.5   I2.3 + I4.8   A1.1   O2.1
```

判定要点：给药途径错误属用法不当（C4.5）。
**注意：此处 P 为 P3.3 而非 P2.1**——给药途径错误尚未造成疗效或安全损害，属需进一步说明的问题，专家标注为 P3.3。这是本类问题的惯例，不要想当然标成 P2.1。

### 案例 16 · 剂量与频次需按肾功能调整

女，61 岁，病毒性感染，予阿昔洛韦 500mg q8h 慢滴。药师查房发现患者肌酐进行性升高至 301μmol/L，存在急性肾损伤。药师提醒医师按肾功能调整剂量为 300mg qd 慢滴，医生接受并更改，患者好转。

```
P2.1   E1.1   E2.2   C4.2 + C4.4   I2.3 + I4.4 + I4.5   A1.1   O2.1
```

判定要点：单次剂量过高（C4.2）与给药频次过多（C4.4）同时成立，故 C 为多选。已出现肾损伤但未造成不可逆后果，专家标 E2.2。

## 三、医嘱执行与患者使用类

### 案例 7 · 依从性差（漏服）

男，38 岁，2 型糖尿病，二甲双胍 0.5g tid。药师随访发现血糖控制欠佳，患者自诉每天 3 次服药经常因上班繁忙忘记。药师宣教依从性重要性并推荐服药打卡软件，患者口头表示后面会定期服用。

```
P1.1   E1.4   E2.4   C6.3   I3.2 + I3.3   A1.4   O1.1
```

判定要点：责任在患者 → E1.4。漏服属执行环节（C6.3），不是 C3 选择问题。
**A1.4（接受但不清楚是否执行）+ O1.1（状态不明）**——患者只是口头答应，实际是否执行未知，如实记录，不要替他判断"已解决"。

### 案例 13 · 未正确使用（吸入技巧）

女，84 岁，慢性哮喘，用吸入皮质类固醇。因口腔鹅口疮就诊，药师检查发现其根本不能正确吸气，吸后也不漱口。药师提供带吸入室的吸入器说明书并告知吸后漱口，一周后鹅口疮消失。

```
P2.1   E1.4   E2.4   C6.7   I3.2 + I3.3   A1.1   O2.1
```

判定要点：药品本身没问题，是使用方法错误 → C6.7（未正确贮存或使用）。责任在患者 → E1.4。

### 案例 14 · 患者自行停药

男，60 岁，高血压 4 个月，用氢氯噻嗪。药师发现近三次血压 165/95 控制不佳，询问后得知患者因不想早上去看孙子时多次上厕所而停服利尿剂。药师告知必须正确服药，患者不愿意，要去找心内科医生讨论。

```
P1.1   E1.4   E2.4   C6.3   I3.2   A2.3   O3.1
```

判定要点：患者明确拒绝 → A2.3（未接受：其他原因），结局未解决且原因是患者不合作 → O3.1。

### 案例 15 · 药物不良反应

男，27 岁，胸腔镜下肺段切除术后，糜蛋白酶 4000U 雾化 bid 化痰。第三次雾化 5 分钟后患者鼻腔出血。药师判断可能为不良反应，鉴于患者自主排痰良好，建议停药，医生采纳，患者停止雾化后鼻腔血止。

```
P2.1   E1.5   E2.4   C1.2   I2.3 + I4.2   A1.1   O2.1
```

判定要点：非人为差错，是患者特殊生理因素导致的不良反应 → C1.2，责任方标为"其他（药品等）"E1.5。

### 案例 12 · 患者拒绝停药

女，56 岁，服泮托拉唑 40mg bid 两年。药学门诊重整用药时发现其 4 个月前已完成幽门螺杆菌根除治疗，药师联系全科医生建议复查评估是否继续用 PPI，医生反馈"我有建议患者，但患者拒绝并执意要求继续服用"。

```
P3.2   E1.4   E2.2   C8.2   I2.3 + I4.9 + I4.2   A1.3   O3.1
```

判定要点：责任在患者 → E1.4。患者主观不愿停 → 患者客观原因（C8.2）。
医生接受建议（A1.3 接受但并未执行），但患者拒绝 → 结局未解决，患者不合作（O3.1）。

### 案例 17 · 转科漏开医嘱

女，80 岁，急性下壁心肌梗死，急诊 PCI 术后第二天由 ICU 转入普通病房。PCI 术后需抗栓干预，药师审核医嘱时发现普通病房医生未给转科患者开具抗血小板药物，告知医生后及时补开。

```
P3.1   E1.1   E2.2   C2.6 + C3.8   I2.3 + I4.3   A1.1   O2.1
```

判定要点：有适应症但未给药 → P3.1、C3.8。发生在科室转换过程中 → C2.6（药物重整问题）。
注意 E2.2：患者已有一段时间未得到应有治疗，DRP 已到达患者，故不是 E2.1。

## 四、管理、流程与系统类

### 案例 1 · 超医保限定支付

男，87 岁，慢性心衰急性加重。医嘱：冻干重组人脑利钠肽 0.5mg 静注泵推。使用第 4 天药师查房发现，该药医保限控支付 3 天，超期需签署自费知情同意书转自费或停药。药师建议医生与患者沟通调整医嘱，医生接受，沟通后停用。

```
P3.3   E1.1   E2.2   C6.10   I2.3 + I5.4   A1.1   O2.1
```

判定要点：医保支付政策属流程监管制度管理（C6.10）。药品已用 4 天 → E2.2。
药师介入含"与患者沟通并调整医嘱"这一具体动作 → I5.4（其他介入，需说明）。

### 案例 10 · 药物经济学选择（医生接受未执行）

男，87 岁，心衰、泌尿道感染，营养状况不佳，予 TPF-D 加强营养。药师查房发现患者无糖尿病且血糖正常，不建议使用糖尿病专用肠内营养制剂，且价格高于能全力 TPF，从药物选择与经济学角度建议调整。医生接受建议但并未执行。

```
P3.3   E1.1   E2.2   C3.1   I2.3   A1.3   O3.2
```

判定要点：无糖尿病却用糖尿病专用制剂 → 品种选择不适宜（C3.1）。
**A1.3（接受但未执行）+ O3.2（未解决：医务人员不合作）**——医生口头接受却没改医嘱，如实记录。

### 案例 19 · 信息系统未拦截

男，69 岁，互联网医院续方。药师线上审核时发现患者续方药物已超 3 个月累积量，但系统未提醒拦截。药师将问题上报信息工程师，工程师立即升级系统，问题得到解决。

```
P3.3   E1.5   E2.1   C6.10 + C7.2   I5.2   A1.1   O2.1
```

判定要点：制度限量（C6.10）叠加系统缺陷（C7.2）。责任方为系统 → E1.5。
介入对象不是医务人员也不是患者，而是工程师 → I5.2。药品尚未配出 → E2.1。

## 判定规律总结

**E2 严重程度（验证集 7/7 成立）**
- 药品未用到患者即被发现（审方、前置审方、审核医嘱时拦截）→ E2.1
- 药品已用上，或患者已处于"该治未治"状态 → E2.2 起
- 判 E2 先问一句"药用了没有"，比权衡伤害程度可靠得多

**P3.3 的适用场景**
管理流程类问题——超医保限控、给药途径错误、续方限量、药品供应、药物经济学选择——不直接造成疗效或安全损害时标 P3.3。
注意案例 4：给药途径错误（iv 应为口服）专家标 P3.3 而非 P2.1。

**E1 涉及主要对象（验证集分布）**
医师 13 例、患者/家属 4 例、其他 3 例；药师与护理人员 0 例。
判据是"问题出在谁的环节"，不是"谁发现了问题"。

**E1 对 C 的约束**

| E1 | 例数 | C 的常见候选 |
|---|---|---|
| E1.1 医师 | 13 | C3 系为主（11 例），其次 C4、C2.6、C6.10 |
| E1.4 患者/家属 | 4 | C6.3 · C6.7 · C6.9 · C8.2（4 例全覆盖） |
| E1.5 其他 | 3 | C1.2 · C3.10 · C6.10 · C7.2 |

**I 的固定搭配**
- 涉及医务人员，几乎必带 I2.3
- 患者教育固定为 I3.2 + I3.3 成对出现
- 案例 12 的 I4.9（增加监测）+ I4.2（停药）说明监测类介入常与药物调整并存

**缺省码的真实分布**
I1.1 未介入：0/20；A3.2 未提出方案：0/20；O1.1 状态不明：2/20 且均为真实结局（案例 7、20）。
→ 缺省码是"如实记录的结果"，不是"信息缺失时的兜底"。信息缺失必须追问，不得静默填充。
